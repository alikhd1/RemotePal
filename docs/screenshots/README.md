# Screenshots

The images referenced from the main README live here. They have to be
captured from a running build (`npm run tauri dev`), so they are not
generated as part of the build.

| File | What to capture |
|---|---|
| `hosts.png` | The Hosts screen: a few saved connections, the sidebar with SSH Keys / S3 / Backup / AI Copilot |
| `copilot.png` | A terminal with the AI Copilot panel open, showing an answer with a table or code block and an approval card |
| `split-sftp.png` | A tab split into two panes with the Files (SFTP) panel open on one of them |
| `compose.png` | The compose bar expanded with the autocompletion list showing |

Tips for consistent shots:

- Use the One Dark theme (the default) so they match each other.
- Resize the window to roughly 1280×800 before capturing.
- Connect to a host with an unremarkable hostname, and avoid leaving real
  IPs, usernames or command output on screen.
- Save as PNG with the exact filenames above; the README links to them
  directly.
